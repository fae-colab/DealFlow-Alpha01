# Case intake checklist

Use this checklist before a case enters the P1.5 dataset.

## Before collecting

- [ ] Confirm whether the source is an agent-originated case, public reconstruction, or synthetic fixture.
- [ ] For an agent-originated case, obtain explicit permission for anonymized research use.
- [ ] Explain that the case may be reviewed in the DealFlow repository and used to evaluate decision quality.
- [ ] Agree whether commission amounts may be exact, rounded, or shown as ranges.

## Freeze the decision point

- [ ] Record the date/time and available working hours.
- [ ] List all candidate actions competing for the agent's attention at that moment.
- [ ] Record the agent's priority order and reasoning before showing DealFlow.
- [ ] Capture each action's deadline, effort, prerequisite, commission basis, and probability assumptions.
- [ ] Attach evidence references or explain why an input is only an assumption.
- [ ] Mark unknown values as null/unknown. Do not fill gaps with plausible guesses.

## Remove identifying details

- [ ] Replace agent identity with a pseudonymous alias.
- [ ] Replace clients, owners, buyers, sellers, landlords, and properties with generated IDs.
- [ ] Remove contact details, exact addresses, unit numbers, listing/transaction references, IDs, and raw chat text.
- [ ] Reduce location detail to a broad Dubai area.
- [ ] Remove metadata from screenshots/documents or, preferably, do not add them.
- [ ] Keep any re-identification key outside the repository.

## After evaluation

- [ ] Save the immutable DealFlow recommendation snapshot ID.
- [ ] Record whether the agent accepted, rejected, or modified each recommendation and why.
- [ ] Record actual time spent and outcome status.
- [ ] Record actual paid commission only when supported by an appropriate source.
- [ ] Do not claim incremental commission without a defensible counterfactual and independent review.
